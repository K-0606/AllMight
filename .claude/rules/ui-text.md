# 介面文字規則（永遠套用）

- 使用者看得到的文字全部是**繁體中文（台灣用語）**：影片、相簿、設定、檔案（不用「視頻」「相冊」「設置」「文件」）。
- 字串寫在 SwiftUI 的 `Text("…")` / `LocalizedStringKey`，讓 Xcode 自動收進 `Localizable.xcstrings`，不要拼接字串，用插值。
- 專有名詞第一次出現可附英文：平均速度（MV）、峰值速度、動作幅度（ROM）、RPE。
- 錯誤訊息要說明發生什麼、使用者可以怎麼做，不道歉、不寫錯誤代碼。PRD 已定義的文字照用。
- 按鈕用動詞：「選擇影片」「鎖定並追蹤」「重新選擇片段」。
- 單位與數字之間空一格：`0.28 m/s`、`42.4 cm`、`200 kg`。
- 程式碼、註解、commit 訊息可以用繁中或英文，同一檔案保持一致。
