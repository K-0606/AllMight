# PRD：AllMight MVP（影片匯入分析）

## 1. 目標

讓有在做重量訓練的人，用手機拍的側面影片，**不用買感測器**就能得到每一下的槓鈴速度，作為調整負荷與判斷疲勞的依據。

**成功標準**
- 一段 3–5 下、30 秒內的 60fps 影片，從按「鎖定並追蹤」到看到結果 ≤ 15 秒（iPhone 13 以上）。
- 在符合拍攝條件的影片上，每下平均速度與參考值誤差 ≤ 0.05 m/s 或 ≤ 10%（以較大者為準）。參考值來源見 OPEN_QUESTIONS。
- 次數判斷正確率 ≥ 95%（測試影片集）。

## 2. 範圍

**MVP 包含**：影片設定、選影片、剪片段、點選槓片、追蹤分析、RPE、結果頁、本機儲存、歷史列表、編輯重量與 RPE、刪除、拍攝建議說明頁。

**MVP 不包含**（列入 Roadmap 後續）：骨架與關節角度、疊圖重播與匯出影片、語音播報、即時相機、1RM/LVP、進步趨勢圖、iCloud 同步、多語系、英磅單位、分享。

## 3. 畫面與需求

### 3.1 首頁（分頁：訓練 / 歷史）
- 「訓練」分頁：大卡片「影片分析：匯入已錄好的影片進行分析」；次要入口「拍攝建議」。
- 「歷史」分頁：見 3.9。

### 3.2 影片設定
| 欄位 | 規則 |
|---|---|
| 動作 | 清單：傳統硬舉、相撲硬舉、背蹲舉、前蹲舉、臥推（最終清單待確認）。預設上次選的。 |
| 重量 | kg，0.5 kg 一格，範圍 1–500。預設上次輸入的。 |
| 槓片直徑 | 預設「45 cm · 標準」；可選 「自訂」輸入 20–50 cm。 |

按鈕「選擇影片」。

### 3.3 選擇影片
- 使用 `PhotosPicker`（只選影片），不請求完整相簿權限。
- 取得後複製到 App 的 Application Support/Videos/。顯示「正在載入影片…」。
- 檢查並阻擋（給出原因文字）：
  - 長度 < 1 秒或 > 3 分鐘
  - 影格率 < 24 fps
  - 慢動作影片（有時間變速）→ 說明「請先在照片 App 中把慢動作改成一般速度，或匯出後再選」（處理方式待確認）
- 影格率 < 50 fps 時允許繼續，但顯示「建議用 60fps 錄影，速度會更準」。

### 3.4 剪出分析片段
- 上方播放器，可播放/暫停；下方縮圖時間軸，左右把手設定起訖，顯示起訖時間（m:ss）。
- 最短 1 秒、最長 60 秒。
- 右上「完成」→ 進入 3.5。

### 3.5 點選槓片
- 顯示片段起點那一幀（已轉正方向）。提示文字：「點一下你要追蹤的槓片」。
- 點擊後在該處出現圓圈（預設直徑為畫面寬的 18%），可拖曳移動、雙指縮放，讓圓圈貼齊槓片外緣。提示：「調整圓圈貼齊槓片外緣」。
- 按鈕「鎖定並追蹤」；次要按鈕「重新選擇片段」。

### 3.6 分析中
- 進度條（0–100%，依已處理幀數）、狀態文字（「追蹤槓片中」→「計算速度」→「判斷次數」）。
- 「取消」按鈕可中止並回到 3.5。
- 失敗情況與文字：
  - 追蹤遺失：「槓片在 m:ss 附近跟丟了，請確認槓片沒有被擋住，再重新點選。」→ 回 3.5
  - 沒有偵測到任何一下：「沒有偵測到完整的動作，請確認片段包含整個動作。」→ 回 3.4

### 3.7 RPE
- 底部彈出：「評估用力程度」，選項 6、7、7.5、8、8.5、9、9.5、10，另有「熱身」「跳過」。

### 3.8 結果頁
- 頂部：影片播放器（可播放片段；**是否疊上槓鈴軌跡線待確認**）。
- 摘要卡：動作名稱、「200 kg × 3 · RPE 6」，按鈕「編輯」。
- 關鍵指標（4 格）：動作幅度（cm）、峰值速度、平均速度（m/s）、速度損失（%）。每格有 ⓘ 說明。
- 次數列表：每下一列「REP n ── 長條 ── 0.28 m/s」，第 2 下起顯示相對第 1 下的變化（↓11%）。點擊展開：
  - 向心：時間 s、峰值速度、平均速度、MPV、幅度 cm
  - 離心：時間 s、峰值速度、平均速度、離心/向心平均速度比 %
  - 與下一下的間隔 s
- 垂直速度曲線（Swift Charts 面積圖），標出每一下的範圍；拖曳可看該時間點的速度。
- 顯示格式：速度 2 位小數、cm 1 位、% 1 位、秒 2 位。

### 3.9 歷史
- 依日期分組列表，每列：動作、重量 × 次數、平均速度、日期時間。
- 點進去是同一個結果頁。左滑刪除（確認後連同影片檔一起刪）。
- 空狀態：「還沒有紀錄。到「訓練」分頁匯入第一段影片。」

### 3.10 拍攝建議（靜態說明頁）
- 手機固定（腳架），從側面拍，鏡頭與槓片面垂直，高度約與槓片同高。
- 整組動作槓片都要在畫面內，不要被身體、架子擋住。
- 用 60fps 錄影，光線充足，不要用慢動作或縮放。

## 4. 非功能需求
- 分析在背景執行，不卡住畫面；離開畫面即取消。
- 記憶體：逐幀處理，不得把整段影片的影格一次載入。
- 隱私：所有資料不離開手機；Info.plist 不需要相簿完整權限描述以外的權限（PhotosPicker 不需權限）。
- 無障礙：支援動態字體、VoiceOver 標籤；數字用等寬數字。
- 深色介面為主（見 skill `swiftui-screens`）。
